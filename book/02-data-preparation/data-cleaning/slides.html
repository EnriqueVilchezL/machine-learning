Filling with mean or median

Let O_j be the examples where feature j is known, and m their count. The mean adds the known values and divides by m:

\bar{x}_j = \frac{1}{m} \sum_{i \in O_j} x_{ij}
(1)

The median sorts the known values, x_{(1)} \le \dots \le x_{(m)}, and takes the middle one:

\tilde{x}_j = \begin{cases} x_{((m+1)/2)} & m \text{ odd} \\ \tfrac{1}{2}\big(x_{(m/2)} + x_{(m/2+1)}\big) & m \text{ even} \end{cases}
(2)

Every gap then receives the chosen value:

x_{ij} \leftarrow \bar{x}_j \ \text{ or } \ \tilde{x}_j \qquad \text{for each } i \notin O_j
(3)
Example

Known commute times: 10, 15, 20, 25 and 80 minutes, so m = 5.

\bar{x} = \tfrac{150}{5} = 30

\tilde{x} = x_{(3)} = 20

Why the median

The single 80-minute commute pulls the mean up to 30. The median stays at 20.

Two outlier rules

The z-score counts how many standard deviations a value lies from the mean. Flag the value when it is more than 3:

z_{ij} = \frac{x_{ij} - \bar{x}_j}{s_j}, \qquad \text{flag if } |z_{ij}| > 3
(4)

The box in Figure 5 goes from Q_1 to Q_3. Its length is the interquartile range:

\text{IQR} = Q_3 - Q_1
(5)

Flag the values below L or above U. Here k is the slider of Figure 5; the usual choice is 1.5.

L = Q_1 - k \cdot \text{IQR}, \qquad U = Q_3 + k \cdot \text{IQR}
(6)
Example

Q_1 = 200 and Q_3 = 300 kWh, so \text{IQR} = 100.

With k = 1.5: L = 50, U = 450. A home using 520 kWh is flagged.

With \bar{x} = 250, s = 60: z = \tfrac{520 - 250}{60} = 4.5, flagged too.

Keep the raw data safe

Figure 7:The raw file stays untouched and the written steps rebuild the clean file. Values used for cleaning, like a median, come from the training rows only.

Data leakage

If test rows help choose the filling value, the test score looks better than it really is.

Statistics from training rows

Let T_j be the training examples where feature j is known. The filling value comes from them alone:

\tilde{x}_j = \operatorname{median}\{\, x_{ij} : i \in T_j \,\}
(7)

The same number fills every gap, in the training rows and in the test rows:

x_{ij} \leftarrow \tilde{x}_j \qquad \text{for every missing } x_{ij}
(8)

Test values never enter (7). The test rows stay unseen, like new data that arrives after the model is in use.

Example

Training temperatures: 22.5, 24.1 and 27.8 °C.

\tilde{x} = 24.1

A test row with no temperature also gets 24.1, whatever the other test values are.

Key ideas

Remember
  • Real data has gaps, repeats, typos, mixed units and impossible values.
  • A model learns from whatever it gets, errors included.
  • Missing values can be dropped, filled or flagged; each choice has a cost.
  • An outlier can be an error or a real rare case: check before removing it.
  • Keep the raw file and write down each cleaning step so it can be repeated.
  • Compute filling values from the training data only.
