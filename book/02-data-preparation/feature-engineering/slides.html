Part 1

Why features matter

A model can only find patterns in the columns we give it.

Good features beat fancy models

No straight cut separates the inner circle from the outer ring. Add one new column, the distance from the center, and the problem becomes easy.

Featuresx₁, x₂
Best single cut0%

Figure 1:120 synthetic points. A cut on x₁ or x₂ alone fails; one cut on the distance separates them all.

Distance as a feature

The new column of Figure 1 is the straight-line distance from the center (0, 0):

r_i = \sqrt{x_{i1}^2 + x_{i2}^2}
(1)

A single threshold on this one number now separates the two classes:

\hat{y} = \begin{cases} \text{A (inner)} & r_i < 1.5 \\ \text{B (outer)} & r_i \ge 1.5 \end{cases}
(2)

The model stays simple. The knowledge that the classes form circles went into the feature.

Example

Point (0.6, 0.8):

r = \sqrt{0.36 + 0.64} = 1, class A

Point (1.2, 1.6):

r = \sqrt{1.44 + 2.56} = 2, class B

Part 2

Building features

Encode categories, combine columns, group values and add curves.

Encoding categories

Figure 2:(a) Numbering the provinces invents an order and distances that do not exist. (b) One-hot encoding gives each province its own 0/1 column.

When numbers are fine

Use 1, 2, 3 only when the order is real: small < medium < large.

One-hot as a vector

A categorical value x becomes K columns, one per category, each 0 or 1:

\mathbf{e}(x) = \big(\mathbb{I}(x = c_1), \ \mathbb{I}(x = c_2), \ \dots, \ \mathbb{I}(x = c_K)\big)
(3)

Exactly one entry is 1, so the entries always add up to 1:

\sum_{k=1}^{K} \mathbb{I}(x = c_k) = 1
(4)

Any two different categories are equally far apart, so no order is invented:

\sum_{k=1}^{K} \big(e_k(c_a) - e_k(c_b)\big)^2 = 2 \qquad \text{for } a \ne b
(5)
Example

The K = 7 provinces in the order of Figure 2.

Cartago: (0,0,1,0,0,0,0)

Limón: (0,0,0,0,0,0,1)

They differ in two entries, so (5) gives 1 + 1 = 2.

Binning: grouping values

Binning turns a number into a group, like age ranges on a survey. The group is then a category.

Bin width10 years
Age 34 goes to30–39
Fewest people in a bin0

Figure 3:Ages of 400 bus passengers (synthetic). Few bins hide the two groups; many bins leave few people in each.

Which bin a value falls in

Split the range from a to b into B bins of equal width:

w = \frac{b - a}{B}
(6)

A value x goes to the bin with this index, counting from 0. The brackets \lfloor \cdot \rfloor round down.

\text{bin}(x) = \left\lfloor \frac{x - a}{w} \right\rfloor
(7)

The bin index is a category. It can be one-hot encoded with (3).

Example

Ages from 20 to 80 in B = 6 bins: w = \tfrac{60}{6} = 10 years.

Age 34: \lfloor \tfrac{14}{10} \rfloor = \lfloor 1.4 \rfloor = 1, the second bin, 30–39.

Squares and products

With temperature x, the straight line is \hat{y} = w_0 + w_1 x. Adding x^2 as a column gives

\hat{y} = w_0 + w_1 x + w_2 x^2
(8)

It is still a weighted sum of columns, so still a linear model. Only the columns changed.

An interaction feature multiplies two columns, so the effect of one depends on the other:

\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + w_3 \, x_1 x_2
(9)
Example

w_0 = 30, w_1 = -2, w_2 = 0.05:

x = 10\!: \ 30 - 20 + 5 = 15

x = 20\!: \ 30 - 40 + 20 = 10

x = 30\!: \ 30 - 60 + 45 = 15

Predicted kWh: cold and hot days use more power, a U shape.

Choosing features

More columns are not always better, and some columns cheat.

Features that leak the answer

Figure 6:Predicting whether a customer will leave (churn). Only the blue columns exist at the moment we predict.

Data leakage

A column known only after the answer makes the test score look perfect, and the model fails in real use. Price per m² leaks the same way when we predict the price.

Key ideas

Remember
  • The right feature can make a hard problem easy.
  • Categories without order need one-hot encoding, not 1, 2, 3.
  • Ratios, differences, date parts and counts add knowledge a model cannot guess.
  • Squared and product features let a linear model follow curves.
  • Drop useless columns, and never use one that is known only after the answer.
