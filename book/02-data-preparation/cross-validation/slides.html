Part 2

k-fold cross-validation

Every example gets a turn in the test set.

The k-fold idea

Cut the data into k folds. Each round, one fold is the test set and the rest train the model.

Round0 of 5
Train / test size—
Average so far—

Figure 2:The 60 examples of Figure 1. Each row is one round, with its score on the right.

Folds in symbols

Split \mathcal{D} into k folds of about the same size, with no example in two folds:

\mathcal{D} = F_1 \cup F_2 \cup \cdots \cup F_k, \qquad |F_m| \approx \frac{n}{k}
(1)

In round m, train \hat{f}_{-m} on all other folds and score it on F_m, for example with the average loss:

s_m = \frac{1}{|F_m|} \sum_{i \in F_m} L\big(y_i, \hat{f}_{-m}(\mathbf{x}_i)\big)
(2)

Each example sits in exactly one fold, so it is tested exactly once.

Example

Figure 2 with n = 60 and k = 5:

|F_m| = 60/5 = 12, and each model trains on 48 examples.

10 of 12 right:

accuracy \tfrac{10}{12} \approx 0.83

0-1 loss \tfrac{2}{12} \approx 0.17

Average and spread

\text{average} = \dfrac{s_1 + s_2 + \cdots + s_k}{k}

The cross-validation estimate

The cross-validation estimate is the average of the k fold scores:

\text{CV}_{(k)} = \frac{1}{k} \sum_{m=1}^{k} s_m
(3)

The standard deviation measures the typical distance of a fold score from that average:

\text{SD} = \sqrt{\frac{1}{k} \sum_{m=1}^{k} \big(s_m - \text{CV}_{(k)}\big)^2}
(4)

A large SD means the score depends a lot on which examples land in the test fold.

Example

Five fold accuracies: 80, 85, 75, 90 and 80%.

\text{CV}_{(5)} = \tfrac{410}{5} = 82\%

Squared gaps: 4, 9, 49, 64, 4. Their mean is 130/5 = 26.

\text{SD} = \sqrt{26} \approx 5.1 points

Rule of thumb

Use 5 or 10 folds. Use leave-one-out only when the data set is very small and the model is cheap to train.

More folds

Each model sees more data, so its score is closer to the final model. Training takes longer.

Fewer folds

Faster, but each model trains on less data and may look a bit worse than it is.

Training size and leave-one-out

Each round leaves one fold out, so every model trains on:

n_{\text{train}} = n - \frac{n}{k} = \frac{k - 1}{k}\, n
(5)

Leave-one-out is the case k = n: each fold is one example and n models are trained.

\text{CV}_{(n)} = \frac{1}{n} \sum_{i=1}^{n} L\big(y_i, \hat{f}_{-i}(\mathbf{x}_i)\big)
(6)

Here \hat{f}_{-i} is trained on every example except example i.

Example

With n = 1000, as in Table 2:

k = 5 \;\Rightarrow\; \tfrac{4}{5} \times 1000 = 800

k = 10 \;\Rightarrow\; \tfrac{9}{10} \times 1000 = 900

k = n \;\Rightarrow\; 1000 - 1 = 999

Stratified folds

With a rare class, random folds can get none of it, or too much.

Stratified k-fold gives every fold the same class proportions as the whole data set.

Figure 4:20 examples, 4 of them rare (orange), in 4 folds. (a) Random. (b) Stratified.

Class shares in each fold

The share of class c in the data is the number of its examples n_c over the total:

\pi_c = \frac{n_c}{n}
(7)

Stratified folds keep that share inside every fold of about n/k examples:

n_{m,c} \approx \pi_c \, \frac{n}{k}
(8)

n_{m,c} is the number of examples of class c in fold m.

Example

Figure 4: 20 examples, 4 rare, 4 folds.

\pi_{\text{rare}} = \tfrac{4}{20} = 0.2

Each fold has 20/4 = 5 examples, so it gets 0.2 \times 5 = 1 rare example.

Picking the best setting

Run cross-validation once for each candidate setting \theta, such as the polynomial degree. Keep the setting with the lowest error:

\hat{\theta} = \underset{\theta}{\arg\min} \ \text{CV}_{(k)}(\theta)
(9)

\arg\min returns the best setting itself. The smallest error is \text{CV}_{(k)}(\hat{\theta}).

Then train the model with \hat{\theta} on all the training data, and only then open the test set.

Example

5-fold errors for three degrees:

degree 1: 0.42
degree 3: 0.11
degree 10: 0.25

\Rightarrow \ \hat{\theta} = 3

Key ideas

Remember
  • A single train-test split can give a lucky or unlucky score.
  • k-fold cross-validation tests on every example once and averages the k scores.
  • Report the average and the spread; 5 or 10 folds are the usual choice.
  • Use stratified folds for classes, time-ordered folds for time, and group folds for groups.
  • Choose settings with cross-validation on the training data and open the test set only once.
