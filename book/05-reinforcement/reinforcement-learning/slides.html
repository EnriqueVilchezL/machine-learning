Reading the symbols

Supervised data was a fixed set \{(\mathbf{x}_i, y_i)\} with the right answer y_i.

Here there is no fixed data set. The agent collects its own experience and receives rewards, never the correct action.

Capital letters S_t, A_t, R_t are random; lowercase s, a, r are particular values. An episode runs until a terminal state.

Delayed reward

Figure 4:A game of eight moves. Only the last step pays. Which moves deserve the credit for the win?

  • Delayed reward: the effect of an action can show up many steps later.
  • No labels: nobody marks the right move at each step.
  • The agent shapes its data: what it sees next depends on what it chose.
Credit assignment

Spreading a final reward back over the steps that led to it is the credit assignment problem.

The return and the value of a state, in Part 2, are the tools for it.

Versus supervised

Supervised examples are fixed and independent. Here a bad early choice can hide the good states from the agent.

Part 2

Rewards and returns

The goal is the total reward over time, not the next reward alone.

Episodes and the return

An episode is one run from a start state to a terminal state at step T. The return adds the rewards that come after step t:

G_t = R_{t+1} + R_{t+2} + \dots + R_T
(1)

Figure 5:One episode as a chain of states, actions and rewards. The return G_0 collects every reward after the start.

The agent's goal: choose actions that make the expected return as large as possible.

Example

A robot pays −1 for each step and gets +10 at the exit.

Rewards -1, -1, -1, +10, so G_0 = -1 - 1 - 1 + 10 = 7.

A path two steps longer gives G_0 = 5. The step cost pushes the agent to be quick.

Discounting the future

A reward k steps later is multiplied by \gamma^k. With \gamma < 1 the sum stays finite even when the task never ends:

G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
(2)

Figure 6:Weights \gamma^k for \gamma = 0.9. A reward 3 steps away counts 0.73 of its size.

The return today is the next reward plus the discounted return from the next step:

G_t = R_{t+1} + \gamma \, G_{t+1}
(3)
Example

Rewards 0, 0, 1 and \gamma = 0.9:

Only the third reward is not zero, so G_0 = 0.9^2 \cdot 1 = 0.81.

With (3): G_1 = 0 + 0.9 \cdot 1 = 0.9, then G_0 = 0 + 0.9 \cdot 0.9 = 0.81.

A policy picks actions

A policy gives a probability to each action in each state:

\pi(a \mid s) = P(A_t = a \mid S_t = s)
(4)
(a) A deterministic policy: one arrow per cell
(b) A random policy in cell (1, 1)

Figure 8:Learning in reinforcement learning means improving the policy.

Example

In cell (1, 1) the policy in (b) gives

\pi(\uparrow \mid s) = 0.6, \pi(\rightarrow \mid s) = 0.3,
\pi(\leftarrow \mid s) = 0.1, \pi(\downarrow \mid s) = 0.

The four numbers add up to 1. A deterministic policy puts all of it on one action.

The value of a state

The value of a state is the return we expect when we start there and follow \pi:

V^\pi(s) = \mathbb{E}_\pi\left[\, G_t \mid S_t = s \,\right]
(5)

Cells near the goal are worth more. Each step away multiplies the value by \gamma = 0.9.

Q^\pi(s, a) is the same idea for a state and a first action. Topic 21 learns it from experience.

Figure 9:Values under the best policy in the grid world of Figure 1, with \gamma = 0.9.

Example

From (2, 3) the best path reaches +1 on its second step: rewards 0, 1, so V = 0.9.

Under a random policy, say half the runs from a cell reach the goal in 3 steps and half in 6.

In 3 steps: G = 0.9^2 = 0.81.
In 6 steps: G = 0.9^5 \approx 0.59.

Value: V = \tfrac{0.81 + 0.59}{2} = 0.70.

Part 3

Exploration and the chapter ahead

To find good actions the agent must sometimes try ones that look worse.

Explore or exploit?

Figure 10:A multi-armed bandit: four slot machines, each with a hidden chance of paying 1. After 8 pulls, machine A looks best, but D was never tried.

The dilemma

Exploit: pull the machine that looks best now.

Explore: try another one; its estimate may be wrong, and it may be better.

Only exploiting can lock onto a poor machine. Only exploring wastes pulls.

Everyday version

Your usual restaurant, or a new one that might be better.

Estimating each machine

The estimate of machine a after t pulls is the average reward it has paid so far:

Q_t(a) = \frac{\text{sum of rewards when } a \text{ was chosen}}{\text{number of times } a \text{ was chosen}}
(6)

We do not need to store every reward. After the N-th pull of a with reward R, move the estimate a step toward R:

Q(a) \ \leftarrow \ Q(a) + \frac{1}{N}\big(R - Q(a)\big)
(7)

R - Q(a) is the surprise. A fixed step size \alpha in place of 1/N gives the shape of the Q-learning update in Topic 21.

Example

Machine B pays 1, 0, 1, 1 in four pulls.

By (6): Q = \tfrac{3}{4} = 0.75.

By (7): after three pulls, Q \approx 0.667.

The fourth reward is 1:

0.667 + \tfrac{1}{4}(0.333) = 0.75.

The ε-greedy rule

Flip a biased coin before each pull:

A_t = \begin{cases} \arg\max_a Q_t(a) & \text{with probability } 1 - \varepsilon \\ \text{a random action} & \text{with probability } \varepsilon \end{cases}
(8)

Figure 11:Chance of each machine under ε-greedy with \varepsilon = 0.1 when A has the highest estimate.

Example

Four machines, \varepsilon = 0.1. The random choice can also land on the best one.

Best machine: 0.9 + \tfrac{0.1}{4} = 0.925.

Each other machine: \tfrac{0.1}{4} = 0.025.

Check: 0.925 + 3 \cdot 0.025 = 1.

Strengths and limits

Table 3:Reinforcement learning at a glance.

Can find strategies no person designedA badly chosen reward leads to odd behavior
Keeps adapting as it collects experienceExploring can be costly or unsafe in the real world

When to use it

When decisions follow one another, success is measured by a score, and the agent can practice, ideally in a simulator.

Key ideas

Remember
  • An agent learns by acting: it sees a state, picks an action, gets a reward and a new state.
  • Rewards score outcomes; they never name the right action.
  • The goal is the return G_t, the discounted sum of future rewards.
  • A policy maps states to actions; V^\pi(s) is the expected return from s.
  • The agent must balance exploring and exploiting; ε-greedy is the simplest way.
