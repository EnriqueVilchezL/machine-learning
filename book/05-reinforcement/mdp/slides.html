Part 1

The MDP model

Five pieces describe the whole problem: states, actions, chances, rewards and a discount.

The Markov property

The next state depends only on the current state and action. The past adds nothing:

P(S_{t+1} = s' \mid S_t, A_t, S_{t-1}, A_{t-1}, \dots, S_0) = P(S_{t+1} = s' \mid S_t, A_t)
(1)

So one table P(s' \mid s, a) describes all the dynamics. For each state and action, the chances form a distribution:

\sum_{s' \in \mathcal{S}} P(s' \mid s, a) = 1, \qquad P(s' \mid s, a) \ge 0
(2)

The state must hold everything that matters for the future, like the battery level for the robot.

Example

The robot is in Low and searches. The next state is Low with chance 0.6 or Flat with 0.4.

It does not matter how long it has been in Low.

0.6 + 0.4 = 1

From High: 0.7 + 0.3 = 1

Episodes and the return

An episode runs from a start state until a terminal state: Flat for the robot, the goal or the pit in the grid. Its return is

G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} = R_{t+1} + \gamma \, G_{t+1}
(3)

Figure 4:One episode of the robot. After a terminal state all rewards are 0.

Example

Rewards +2, +2, -3, \gamma = 0.9:

G_0 = 2 + 0.9 \cdot 2
+\, 0.81 \cdot (-3)

= 2 + 1.8 - 2.43 = 1.37

Why discount

With \gamma \lt 1 the sum stays finite even if the episode never ends, and sooner rewards count more.

Part 2

Policies and values

A rule for acting, and how much return that rule earns from each state.

A policy maps states to actions

A policy \pi(s) picks an action in every state. A random policy \pi(a \mid s) gives a chance to each action.

Policy B is shorter but passes next to the pit, where a slip costs −1. Which is better? We need a number for each policy.

Figure 5:Two policies on the grid world. The number below each grid is the expected return from the start, computed later in this part.

Value of a state

The state value is the expected return when we start in s and follow \pi:

V^\pi(s) = \mathbb{E}_\pi \big[ G_t \mid S_t = s \big]
(4)

The action value fixes the first action a, then follows \pi:

Q^\pi(s, a) = \mathbb{E}_\pi \big[ G_t \mid S_t = s, \ A_t = a \big]
(5)

Expected means averaged over all the ways the episode can go. Larger is better.

Example

Policy: wait in Low. The rewards are 1, 1, 1, \dots forever.

G = 1 + 0.9 + 0.9^2 + \cdots

= \frac{1}{1 - 0.9} = 10

So V^\pi(\text{Low}) = 10.

The Bellman equation

The return is the first reward plus the discounted return after it. Averaging over actions and next states gives

V^\pi(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \big[ R(s, a, s') + \gamma V^\pi(s') \big]
(6)

One equation per state. The value of a state is linked to the values of the states one step ahead. The same idea for an action:

Q^\pi(s, a) = \sum_{s'} P(s' \mid s, a) \big[ R(s, a, s') + \gamma V^\pi(s') \big]
(7)
Example

Policy: search in High, wait in Low.

V^\pi(\text{Low}) = 10
V^\pi(\text{High}) = 12.70

Check High:

0.7(2 + 0.9 \cdot 12.70)
+\, 0.3(2 + 0.9 \cdot 10)
= 9.40 + 3.30 = 12.70

Example: an action

Q^\pi(\text{Low}, \text{recharge})

= 0 + 0.9 \cdot 12.70 = 11.43

More than the 10 of waiting.

Part 3

Finding the best policy

Replace the average over actions with the best action, and repeat.

Optimal values

The optimal value V^*(s) is the largest value any policy can reach. It solves the Bellman optimality equation:

V^*(s) = \max_{a} \sum_{s'} P(s' \mid s, a) \big[ R(s, a, s') + \gamma V^*(s') \big]
(8)

Once we know V^*, a best policy looks one step ahead and takes the best action, the greedy one:

\pi^*(s) = \underset{a}{\arg\max} \sum_{s'} P(s' \mid s, a) \big[ R(s, a, s') + \gamma V^*(s') \big]
(9)

The sum inside is Q^*(s, a), so V^*(s) = \max_a Q^*(s, a).

Example

Robot: V^*(\text{High}) = 15.75, V^*(\text{Low}) = 14.17.

In Low:

search: 0.6(2 + 0.9 \cdot 14.17)
+\, 0.4(-3) = 7.65

wait: 1 + 0.9 \cdot 14.17 = 13.76

recharge: 0.9 \cdot 15.75 = 14.17

Best: recharge.

Value iteration

Turn equation (8) into an update. V_k is the guess after k sweeps:

V_{k+1}(s) = \max_{a} \sum_{s'} P(s' \mid s, a) \big[ R(s, a, s') + \gamma V_k(s') \big]
(10)
  1. Start with V_0(s) = 0 for every state.
  2. Sweep: update every state with (10), using the old values.
  3. Repeat until the largest change is below a small threshold.
  4. Read the policy with the greedy rule (9).

With \gamma \lt 1 the values always converge to V^*.

Example

Cell (3, 3), action East, \gamma = 0.9, step -0.04.

Sweep 1, all V_0 = 0:
0.8(1) + 0.1(-0.04) + 0.1(-0.04)
= 0.792

Sweep 2, slip north (stays):
-0.04 + 0.9 \cdot 0.792 = 0.673
slip south:
-0.04 + 0.9 \cdot (-0.04) = -0.076

0.8 + 0.1(0.673) + 0.1(-0.076)
= 0.860

Strengths and weaknesses

Table 2:MDPs and dynamic programming at a glance.

StrengthsWeaknesses
One clear language for sequential decisionsNeeds the transition chances and the rewards
Handles chance: plans account for slipsEvery sweep touches every state
Value and policy iteration always convergeAssumes the agent sees the full state
Values explain why an action is preferredResults depend on how rewards are designed
Basis for Q-learning and later methodsHard with continuous states and actions
When to use it

When the states fit in a table and the dynamics are known or can be estimated, compute the policy directly with value or policy iteration.

Key ideas

Remember
  • An MDP has states, actions, transition chances, rewards and a discount.
  • Markov property: the next state depends only on the current state and action.
  • A policy picks actions; its value is the expected discounted return from each state.
  • Bellman equations link each value to the values one step ahead.
  • Value iteration repeats the max update; the greedy policy of V^* is optimal.
