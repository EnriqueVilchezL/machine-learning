Part 1

Learning without a model

We do not know how the world works. We can only act and watch what happens.

Where we left off

In Topic 20, with P and R known, value iteration solves the Bellman optimality equation for Q^*:

Q^*(s, a) = \sum_{s'} P(s' \mid s, a) \big[ R(s, a, s') + \gamma \max_{a'} Q^*(s', a') \big]
(1)

With Q^* in hand, acting well is easy: in each state, take the action with the largest value.

\pi^*(s) = \underset{a}{\arg\max} \ Q^*(s, a)
(2)

This topic learns Q^* when P and R are unknown.

Example: equation (1)

Moving right always reaches s', with r = 0, \gamma = 0.9 and \max_{a'} Q^*(s', a') = 0.79:

Q^*(s, \rightarrow) = 0 + 0.9 \cdot 0.79 \approx 0.71

Example: equation (2)

Q^*(s, \cdot) for \uparrow \rightarrow \downarrow \leftarrow: 0.66, 0.71, 0.55, 0.60

\Rightarrow \ \pi^*(s) = \ \rightarrow

No model, only experience

A robot, a game or a thermostat rarely comes with its transition probabilities written down.

What the agent can do is try an action and record one experience tuple (s, a, r, s'). Q-learning builds Q^* from these tuples alone.

Figure 1:(a) With a model, value iteration computes Q^*. (b) Without one, the agent learns from a stream of steps.

The Q-table

Q-learning stores one number for every state and action: rows are states, columns are actions.

It starts with every entry at 0. Learning fills it in. The greedy action is the largest entry of the row.

Figure 2:A world with five states and a goal G, \gamma = 0.9. (a) The table Q^*. (b) The same numbers drawn as four triangles per cell; arrows show the greedy action.

Learning in small steps

To average numbers that arrive one at a time, keep the mean and move it toward each new number x_n:

\bar{x}_n = \bar{x}_{n-1} + \frac{1}{n} \big( x_n - \bar{x}_{n-1} \big)
(3)

Replace 1/n by a fixed step size \alpha, and the new number by a target:

\text{estimate} \leftarrow \text{estimate} + \alpha \, \big( \text{target} - \text{estimate} \big)
(4)

Learning from such targets, step by step, is called temporal-difference (TD) learning.

Example: equation (3)

Numbers 4, 8, 3:

\bar{x}_2 = 4 + \tfrac{1}{2}(8 - 4) = 6

\bar{x}_3 = 6 + \tfrac{1}{3}(3 - 6) = 5

Same as (4 + 8 + 3)/3 = 5.

Example: equation (4)

With \alpha = 0.5: 6 + 0.5(3 - 6) = 4.5. Recent numbers count more.

Part 2

The Q-learning update

One step of experience changes one entry of the table.

Target, error, update

Target: the reward we got, plus the discounted value of the best action in the next state.

y = r + \gamma \max_{a'} Q(s', a')
(5)

TD error: how much the target differs from the current estimate.

\delta = r + \gamma \max_{a'} Q(s', a') - Q(s, a)
(6)

Update: move the entry a fraction \alpha of the way to the target.

Q(s, a) \leftarrow Q(s, a) + \alpha \, \delta
(7)
Example

Q(s, a) = 0.5, r = 0, \gamma = 0.9, \max_{a'} Q(s', a') = 0.8, \alpha = 0.1

y = 0 + 0.9 \cdot 0.8 = 0.72

\delta = 0.72 - 0.5 = 0.22

Q(s, a) \leftarrow 0.5 + 0.1 \cdot 0.22 = 0.522

Terminal states

If s' ends the episode, its value is 0 and the target is just r.

The algorithm

Q-learning repeats the same small loop for many episodes. Every step uses one tuple (s, a, r, s') and changes one entry.

The agent never needs P or R. The environment answers each action, and the table slowly absorbs the answers.

Part 3

Exploration and settings

How to try new actions, how to set the knobs, and where tables stop working.

Why pure greedy gets stuck

A greedy agent only takes the action that looks best now. Once the left path pays something, the right action keeps its starting value 0 and is never tried.

A few random actions are enough to discover the +10 on the right. Its value then flows back and the greedy choice changes.

Figure 6:A corridor with \gamma = 0.9 and rewards only at the two ends. Numbers are Q(s, \leftarrow) and Q(s, \rightarrow).

Exploring with ε-greedy

With probability \varepsilon pick a random action; otherwise pick the greedy one. With |\mathcal{A}| actions:

\pi(a \mid s) = \begin{cases} 1 - \varepsilon + \dfrac{\varepsilon}{|\mathcal{A}|} & \text{if } a = \arg\max_{a'} Q(s, a') \\[8pt] \dfrac{\varepsilon}{|\mathcal{A}|} & \text{otherwise} \end{cases}
(8)

The greedy action also wins some random draws, hence the extra \varepsilon / |\mathcal{A}|.

Decaying \varepsilon: explore a lot at first, when the table knows little, and less later.

Example

Four actions, \varepsilon = 0.2:

greedy action: 1 - 0.2 + 0.05 = 0.85

each other action: 0.2 / 4 = 0.05

Example: decay

Start at \varepsilon = 1 and multiply by 0.99 after each episode: 0.37 after 100 episodes, 0.05 after 300.

Q-learning and SARSA

Q-learning is off-policy: it acts \varepsilon-greedily but learns the greedy policy. SARSA is on-policy: its target uses the action a' it will really take next.

y_{\text{SARSA}} = r + \gamma \, Q(s', a') \qquad \text{vs} \qquad y_{\text{Q}} = r + \gamma \max_{a'} Q(s', a')
(9)

Figure 8:Cliff walking. Each move costs 1; falling costs 100. Q-learning learns the shortest path along the edge and falls now and then while exploring. SARSA counts its own random moves and learns a safer path.

Example

r = 0, \gamma = 0.9. In s' the best action has Q = 0.8, but the agent explores and picks a' with Q(s', a') = 0.3.

SARSA: 0 + 0.9 \cdot 0.3 = 0.27

Q-learning: 0 + 0.9 \cdot 0.8 = 0.72

When it converges

In a finite problem, Q-learning reaches Q^* if two conditions hold:

1. Every pair (s, a) keeps being tried, again and again.

2. The step size \alpha shrinks over time, but slowly, for example 1/n.

A constant \alpha keeps reacting to noise; in practice a small constant is usually good enough.

Figure 9:One entry learned from random rewards, 0 or 1 with equal chance. Its true value is 0.5.

Tables do not scale

A table needs one entry per state and action, and every entry must be visited many times.

For large or continuous problems we replace the table by a function with weights that maps a state to its action values. A neural network used this way is a deep Q-network (chapter 6).

Figure 10:(a) Number of states, log scale. (b) A function that generalizes from visited states to similar ones.

Strengths and weaknesses

Table 2:Q-learning at a glance.

StrengthsWeaknesses
Learns from experience; no model of P and RNeeds many episodes, even on small problems
Simple update: one entry per stepThe table grows with every state and action
Off-policy: learns the best policy while exploringResults depend on \alpha, \gamma, \varepsilon and the rewards
Reaches Q^* in finite problems under mild conditionsContinuous states need a function, not a table
The policy is read directly from the tableThe max over noisy estimates tends to overestimate
When to use it

Small problems with a few discrete states and actions, a simulator to practice in, and no model of the environment.

Key ideas

Remember
  • Q-learning learns Q^* from tuples (s, a, r, s') without knowing P or R.
  • Each step moves one entry toward r + \gamma \max_{a'} Q(s', a') by a fraction \alpha of the TD error.
  • \varepsilon-greedy mixes random actions with greedy ones so that better paths can be found.
  • Q-learning is off-policy; SARSA learns the policy it follows and plays safer.
  • Tables only fit small problems; large ones replace the table by a function.
