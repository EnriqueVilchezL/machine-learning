Part 1

Building a hierarchy

Start with every example alone and merge, one step at a time.

Bottom-up or top-down

k-means needs K before it starts. A hierarchy keeps every grouping, and you choose K afterwards.

Agglomerative (bottom-up): start with each example alone and merge the closest pair of clusters.

Divisive (top-down): start with one cluster and split it. This topic uses the agglomerative version.

Distances and the merge rule

Euclidean distance between two examples: one squared gap per feature, added, then a square root.

d(\mathbf{a}, \mathbf{b}) = \sqrt{\sum_{j=1}^{d} (a_j - b_j)^2}
(1)

At every step, merge the pair of clusters with the smallest distance D between them:

(A^{*}, B^{*}) = \underset{A \neq B}{\arg\min} \; D(A, B)
(2)

Each merge turns two clusters into one, so going from n clusters to a single cluster takes

\text{number of merges} = n - 1
(3)
Example

Three examples: p = (1, 1), q = (4, 5), r = (5, 5).

d(p, q) = \sqrt{3^2 + 4^2} = 5

d(q, r) = \sqrt{1^2 + 0^2} = 1

d(p, r) = \sqrt{4^2 + 4^2} \approx 5.66

First merge: \{q, r\}. With n = 3 there are 2 merges.

Part 2

Linkage and the dendrogram

How far apart two groups are, and how to read the tree.

Distance between clusters

Once a cluster has several examples, we need a distance between two groups. This choice is called the linkage.

Single: the closest pair. Complete: the farthest pair. Average: the mean over all pairs.

Ward: how much the spread inside the clusters grows if A and B merge.

Figure 3:Two clusters with three examples each. The thick line is what each linkage measures.

Linkage formulas

Single linkage: the distance of the closest pair, one example from each cluster.

D_{\text{single}}(A, B) = \min_{\mathbf{a} \in A, \, \mathbf{b} \in B} d(\mathbf{a}, \mathbf{b})
(4)

Complete linkage: the distance of the farthest pair.

D_{\text{complete}}(A, B) = \max_{\mathbf{a} \in A, \, \mathbf{b} \in B} d(\mathbf{a}, \mathbf{b})
(5)

Average linkage: add the distances of all |A| \cdot |B| pairs and divide by the number of pairs.

D_{\text{average}}(A, B) = \frac{1}{|A|\,|B|} \sum_{\mathbf{a} \in A} \sum_{\mathbf{b} \in B} d(\mathbf{a}, \mathbf{b})
(6)
Example

A = \{(0, 0), (0, 4)\}, B = \{(3, 0), (6, 0)\}.

The four pair distances: 3, 6, 5 and \sqrt{52} \approx 7.21.

Single: 3. Complete: 7.21.

Average: \tfrac{3 + 6 + 5 + 7.21}{4} \approx 5.30

Ward's linkage

The within-cluster sum of squares adds the squared distance from each example to the mean of its cluster:

W(A) = \sum_{\mathbf{a} \in A} \lVert \mathbf{a} - \boldsymbol{\mu}_A \rVert^2
(7)

Ward merges the pair that makes this sum grow the least. The growth has a short formula:

\Delta(A, B) = W(A \cup B) - W(A) - W(B) = \frac{|A|\,|B|}{|A| + |B|} \, \lVert \boldsymbol{\mu}_A - \boldsymbol{\mu}_B \rVert^2
(8)

Large clusters with distant means are costly to merge, so Ward builds compact groups. It is the same sum that k-means makes small (Topic 16).

Example

Same A and B: \boldsymbol{\mu}_A = (0, 2), \boldsymbol{\mu}_B = (4.5, 0).

\lVert \boldsymbol{\mu}_A - \boldsymbol{\mu}_B \rVert^2 = 4.5^2 + 2^2 = 24.25

\Delta = \tfrac{2 \cdot 2}{2 + 2} \cdot 24.25 = 24.25

Check: W(A) = 8, W(B) = 4.5, W(A \cup B) = 36.75, and 36.75 - 8 - 4.5 = 24.25.

Reading a dendrogram

Each leaf is one example. Two branches join at the height where their clusters merged.

Low joins mean very similar examples. A long vertical branch is a group that stays apart for a long time.

Only heights carry meaning. Any join can be flipped left to right, so neighboring leaves are not always close.

Figure 5:Six examples, average linkage. The dashed cut crosses three branches: three clusters.

Cutting the tree

Move the cut line. Every branch it crosses becomes one cluster.

Part 3

Choosing and limits

Which linkage to use, and where the method struggles.

Chaining and compact clusters

Single linkage needs only one close pair to merge, so it follows thin chains of points. Complete linkage looks at the farthest pair and prefers compact groups.

(a) Single linkage: the bridge chains both groups
(b) Complete linkage: two compact groups

Figure 7:Two groups joined by a thin bridge, plus one far example. Each tree is cut into K = 2 clusters.

Scaling matters

Every linkage starts from distances between examples, so a feature with large units decides the tree. Scale the features first (Topic 4).

(a) Raw units: spending decides the split
(b) Both features scaled to 0 to 1: hours decide

Cost and greedy merges

The method needs the distance between every pair of examples, and it never undoes a merge.

(a) The number of pairs grows like n^2
(b) Greedy: an early merge is final

When to use it

Small or medium data sets, when K is unknown or when you want to see how groups nest inside each other.

Key ideas

Remember
  • Agglomerative clustering starts with n clusters of one and merges the closest pair n - 1 times.
  • The linkage defines the distance between clusters: single, complete, average or Ward.
  • The dendrogram records every merge at the height of its distance.
  • Cutting the tree at a height gives K clusters; cut inside a long gap.
  • Single linkage chains; complete and Ward give compact groups. Scale features first.
  • The cost grows at least like n^2, and merges are never undone.
