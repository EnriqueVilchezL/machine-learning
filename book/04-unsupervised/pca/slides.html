Part 1

Why reduce dimensions

Many features often repeat the same information.

Too many, too similar

Data often has many features: pixels of an image, thousands of genes, dozens of survey answers.

Many features move together and repeat the same information.

We cannot plot 50 features. Two or three new ones that keep most of the spread can be plotted.

Figure 1:(a) Two columns rise and fall together. (b) One number along the line describes both features.

Shadows of a cloud

Projecting points onto a line is like casting their shadow on it. Each point becomes one number: its position on the line.

Some lines give a wide shadow and keep points apart. Others squeeze them together and lose the shape.

PCA looks for the line with the widest shadow, then the next one, and so on.

Figure 2:The same 30 points projected onto two lines. Orange marks are the shadows.

Part 2

Finding the components

Directions of largest variance, one after another.

Center and scale first

PCA measures spread around the mean, so we move the mean to the origin. Features in different units are also standardized (Topic 4).

(a) Raw data, far from the origin
(b) Centered: weight dominates
(c) Standardized: both spreads equal 1

Figure 3:Height in meters and weight in kilograms for 60 people. In (b) the height spread is tiny next to the weight spread, so the widest direction would only follow weight.

Centering as a formula

The mean vector averages each feature over the n examples:

\bar{\mathbf{x}} = \frac{1}{n} \sum_{i=1}^{n} \mathbf{x}_i
(1)

Centering subtracts it from every example, so each feature now has mean zero:

\tilde{\mathbf{x}}_i = \mathbf{x}_i - \bar{\mathbf{x}}
(2)

To standardize, also divide feature j by its standard deviation s_j:

\tilde{x}_{ij} = \frac{x_{ij} - \bar{x}_j}{s_j}
(3)
Example

Points (2, 1), (4, 3), (6, 8).

\bar{\mathbf{x}} = \big(\tfrac{12}{3}, \tfrac{12}{3}\big) = (4, 4)

Centered: (-2, -3), (0, -1), (2, 4). Each column sums to 0.

The rows of X

Stacking the centered examples as rows gives the n \times d matrix \mathbf{X}.

Turn the line and watch the shadows. The first principal component is the angle where their variance is largest.

Scores and the first component

The score of example i is its position along the unit vector \mathbf{w}_1: multiply feature by feature and add.

z_{i1} = \mathbf{w}_1^\top \tilde{\mathbf{x}}_i = \sum_{j=1}^{d} w_{j1}\, \tilde{x}_{ij}, \qquad \lVert \mathbf{w}_1 \rVert = 1
(4)

The first component is the unit direction whose scores have the largest variance. The data is centered, so the scores have mean 0 and their variance is the average square:

\mathbf{w}_1 = \underset{\lVert \mathbf{w} \rVert = 1}{\arg\max} \ \frac{1}{n} \sum_{i=1}^{n} \big(\mathbf{w}^\top \tilde{\mathbf{x}}_i\big)^2
(5)

The length is fixed at 1: a longer \mathbf{w} would make the variance as large as we like.

Example

\mathbf{w}_1 = (0.6, 0.8) has length \sqrt{0.36 + 0.64} = 1.

For \tilde{\mathbf{x}}_i = (2, 1):

z_{i1} = 0.6 \cdot 2 + 0.8 \cdot 1 = 2.0

Scores as new coordinates

The second component \mathbf{w}_2 is perpendicular to \mathbf{w}_1 and takes the largest remaining variance.

The scores (z_{i1}, z_{i2}) are the coordinates in the new axes. The cloud is only rotated, and the new features are uncorrelated.

Figure 5:(a) Data of Figure 4; arrow length shows the spread. (b) The same points in score coordinates.

Covariance and eigenvectors

The covariance matrix collects the variance of each feature (diagonal) and how each pair of features varies together (off the diagonal):

\mathbf{S} = \frac{1}{n} \mathbf{X}^\top \mathbf{X}, \qquad s_{jl} = \frac{1}{n} \sum_{i=1}^{n} \tilde{x}_{ij}\, \tilde{x}_{il}
(6)

A known result from linear algebra: the components are the eigenvectors of \mathbf{S}. Multiplying by \mathbf{S} only stretches them, by the eigenvalue \lambda_k:

\mathbf{S}\,\mathbf{w}_k = \lambda_k\, \mathbf{w}_k, \qquad \lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_d \ge 0
(7)

The eigenvalue \lambda_k is the variance of the scores on component k. Sorting by eigenvalue sorts the components by importance.

Example

\mathbf{S} = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}

\mathbf{w}_1 = \tfrac{1}{\sqrt{2}}(1, 1):

\mathbf{S}\mathbf{w}_1 = \tfrac{1}{\sqrt{2}}(3, 3) = 3\,\mathbf{w}_1

so \lambda_1 = 3.

\mathbf{w}_2 = \tfrac{1}{\sqrt{2}}(1, -1) gives \lambda_2 = 1.

Total variance:

2 + 2 = 3 + 1 = 4

Keeping fewer components

Keep one score per point and rebuild the point from it. The rebuilt points fall on the kept line.

Variance kept100%
Average squared error0

The error equals the variance of the dropped component.

Figure 6:The data of Figure 4. Gray rings: original points. Lines: what each point loses.

Reconstruction as a formula

Start at the mean and walk z_{ik} steps along each kept direction:

\hat{\mathbf{x}}_i = \bar{\mathbf{x}} + \sum_{k=1}^{q} z_{ik}\, \mathbf{w}_k
(8)

With q = d the reconstruction is exact. With fewer components, the average squared error is the variance left out:

\frac{1}{n} \sum_{i=1}^{n} \lVert \mathbf{x}_i - \hat{\mathbf{x}}_i \rVert^2 = \sum_{k=q+1}^{d} \lambda_k
(9)

So the components with the largest variance are also the ones that rebuild the data with the smallest error.

Example

\bar{\mathbf{x}} = (5, 3), \mathbf{w}_1 = (0.6, 0.8),

z_{i1} = 2:

\hat{\mathbf{x}}_i = (5 + 1.2,\ 3 + 1.6)

\phantom{\hat{\mathbf{x}}_i} = (6.2, 4.6)

With the 2 × 2 example

Keeping only \mathbf{w}_1 leaves an error of \lambda_2 = 1, a quarter of the total 4.

Part 3

How many components

Explained variance, reconstruction error and the limits of PCA.

The scree plot

Each bar is the share of the total variance one component explains. The line adds them up.

Component q alone0%
Cumulative0%
Below 80%

Figure 7:A made-up data set with 8 standardized features. The bars drop fast, then flatten: the elbow.

Explained variance

The share of the total variance explained by component k:

\text{PVE}_k = \frac{\lambda_k}{\sum_{j=1}^{d} \lambda_j}
(10)

The cumulative share of the first q components. One minus it is the relative reconstruction error of equation (9):

\text{CPVE}_q = \frac{\sum_{k=1}^{q} \lambda_k}{\sum_{j=1}^{d} \lambda_j}
(11)

Choose q at the elbow, at a target such as 80% or 90%, or by cross-validation when PCA feeds a supervised model.

Example

Figure 7: eigenvalues 3.6, 1.9, 0.9, 0.6, 0.4, 0.3, 0.2, 0.1. They add to 8.

\text{PVE}_1 = 3.6 / 8 = 45\%

3.6 + 1.9 + 0.9 = 6.4

\text{CPVE}_3 = 6.4/8 = 80\%

Why 8

Each standardized feature has variance 1, so the total is d.

Where PCA falls short

(a) Only straight directions
(b) Raw units decide the answer
(c) Labels are ignored

Figure 9:(a) Points on an arc: one straight line misses the curve. (b) Unscaled, PC1 follows the feature with the largest numbers. (c) PC1 runs along both classes and mixes them; PC2 separates them. Also, each component mixes all features, which makes it harder to interpret.

Strengths and weaknesses

Table 2:PCA at a glance.

StrengthsWeaknesses
Fewer features, little information lostFinds only straight (linear) directions
New features are uncorrelatedResults change with units: scale first
Plots many-feature data in 2-D or 3-DComponents mix all features, hard to interpret
One exact answer, no random startIgnores labels: top variance may not separate classes
Removes noise and speeds up later modelsSquared distances make it sensitive to outliers
When to use it

Many related numeric features, to plot the data or as a step before a supervised model.

Key ideas

Remember
  • PCA replaces many related features with a few new ones, the scores.
  • Center the data, and standardize it when features use different units.
  • Each component is the direction of largest remaining variance, perpendicular to the earlier ones.
  • The components are eigenvectors of the covariance matrix; eigenvalues are their variances.
  • Choose q with the scree plot or cumulative explained variance. The dropped variance is the reconstruction error.

Going further

Kernel PCA and autoencoders find curved low-dimensional structure that plain PCA misses.
