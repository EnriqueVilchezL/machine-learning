Part 1

Finding groups

No labels, no teacher: only the features and how close the examples are.

Data without labels

In supervised learning every example comes with its answer. In unsupervised learning we only have the features.

Clustering divides the data into groups: examples in the same group are close, examples in different groups are far apart.

Distance to a centroid

k-means measures closeness with the squared Euclidean distance: one squared gap per feature, added up.

\lVert \mathbf{x}_i - \boldsymbol{\mu}_k \rVert^2 = \sum_{j=1}^{d} (x_{ij} - \mu_{kj})^2
(1)

It is the straight-line distance without the square root. The nearest centroid is the same with or without the root.

Squaring makes large gaps count much more: a point twice as far adds four times as much.

Example

Example \mathbf{x} = (2, 3) and centroid \boldsymbol{\mu} = (5, 7):

(2 - 5)^2 + (3 - 7)^2

= 9 + 16 = 25

The straight-line distance is \sqrt{25} = 5.

Part 2

The algorithm

Assign every example to a centroid, move every centroid to its group, repeat.

Two steps, repeated

Place K centroids on random examples. Then alternate an assign step and an update step.

Figure 3:(a) Start: three centroids at random examples. (b) Assign: each example takes the color of its nearest centroid. (c) Update: each centroid moves to the mean of its examples.

Assign and update

Assign step: example i joins the cluster whose centroid is nearest.

c_i = \underset{k}{\arg\min} \ \lVert \mathbf{x}_i - \boldsymbol{\mu}_k \rVert^2
(2)

Update step: each centroid becomes the mean of the examples in its cluster.

\boldsymbol{\mu}_k = \frac{1}{|C_k|} \sum_{i \in C_k} \mathbf{x}_i
(3)

|C_k| is the number of examples in cluster k. \arg\min_k returns the cluster number, not the distance.

Example: assign

\mathbf{x} = (2, 3), \boldsymbol{\mu}_1 = (1, 1), \boldsymbol{\mu}_2 = (5, 7)

1^2 + 2^2 = 5 \ \text{ vs } \ 3^2 + 4^2 = 25

\Rightarrow c = 1

Example: update

C_1 = \{(1, 2), (3, 2), (2, 5)\}

\boldsymbol{\mu}_1 = \big(\tfrac{1 + 3 + 2}{3}, \tfrac{2 + 2 + 5}{3}\big) = (2, 3)

What k-means minimizes

The inertia, or within-cluster sum of squares, adds the squared distance from every example to its own centroid:

J = \sum_{k=1}^{K} \sum_{i \in C_k} \lVert \mathbf{x}_i - \boldsymbol{\mu}_k \rVert^2
(4)

Assign never increases J: each example moves to a centroid that is at least as close.

Update never increases J: for a fixed group, the mean is the point with the smallest sum of squared distances.

Small J means tight clusters.

Example

Group \{(1, 2), (3, 2), (2, 5)\}.

With the mean (2, 3):

2 + 2 + 4 = 8

With the point (1, 2) instead:

0 + 4 + 10 = 14

The mean gives the smaller sum.

When to stop

J goes down at every step and never goes back up.

Stop when no example changes cluster: then the centroids and J stop changing too. In practice, also set a maximum number of iterations.

The algorithm always stops, but at a local minimum of J, which may not be the best one.

Smarter starts: k-means++

Pick the first centroid at random. Each next centroid is a random example, with chance proportional to its squared distance to the nearest centroid so far.

Scaling matters

(a) Raw units: income in dollars decides alone
(b) Both features scaled to 0 to 1

Where k-means struggles

(a) Groups that are not round
(b) Groups of different sizes
(c) A few outliers

When to use it

A good first clustering method for numeric, scaled features when the groups are compact and roughly round.

Key ideas

Remember
  • Clustering finds groups in data without labels; k-means describes each group by its centroid.
  • The algorithm alternates two steps: assign each example to the nearest centroid, then move each centroid to the mean.
  • Both steps lower the inertia J, so k-means always stops, but at a local minimum.
  • Choose K with the elbow of J, run several starts (k-means++), and scale the features first.
  • k-means prefers round groups of similar size and is pulled by outliers.
