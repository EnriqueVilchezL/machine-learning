Part 1

Data that comes in order

When the position of each item carries meaning, the model needs a memory.

Sequences everywhere

Many data sets are sequences: items that arrive one after another, where the order carries meaning.

A sequence is a table: one row per time step, one column per feature. Its length T changes from one sequence to the next.

Figure 1:Five kinds of sequences. Illustrative data.

Why a dense network struggles

A dense network (Topic 23) has a fixed number of input slots, one weight per slot.

Lengths vary: short inputs need padding, long ones do not fit.

Patterns move: the same words at another position meet other weights, so they must be learned again.

Figure 2:A dense network with five input slots, one word per slot.

A memory that updates

Read the sequence one item at a time, the way we read a sentence.

Keep a short summary of everything read so far: the hidden state \mathbf{h}_t, a vector of a few numbers.

Each step mixes the old state with the new item. The same rule works for any length.

Figure 3:Three numbers of state after each word. Orange bars are positive, blue bars negative. Illustrative values.

Part 2

The recurrent cell

One small network, applied at every step, that feeds its state back to itself.

From a dense layer to a cell

A dense layer (Topic 23) maps an input to an output with weights, a bias and an activation:

\mathbf{a} = g(\mathbf{W}\mathbf{x} + \mathbf{b})
(1)

The recurrent cell adds one term: the previous state, with its own weights.

\mathbf{h}_t = \tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{W}_{xh}\mathbf{x}_t + \mathbf{b}_h)
(2)

An ordinary dense layer reads the state and gives the output at step t:

\hat{\mathbf{y}}_t = \text{softmax}(\mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y)
(3)
Example

One number of state, W_{xh} = 1, W_{hh} = 0.5, b_h = 0.

First input x_1 = 1, and h_0 = 0:

h_1 = \tanh(0.5 \cdot 0 + 1 \cdot 1)

= \tanh(1) \approx 0.762

Why tanh

It keeps every number of the state between −1 and 1, so the state cannot grow without bound.

Three steps by hand

Example

Weights of the last slide:

h_t = \tanh(0.5\,h_{t-1} + x_t)

h_1 = \tanh(1) = 0.762

h_2 = \tanh(0.381) = 0.363

h_3 = \tanh(1.182) = 0.828

x_3 = x_1, yet h_3 \neq h_1: the state still remembers the first input.

Figure 5:Output weights \mathbf{W}_{hy} = (2, -2), \mathbf{b}_y = \mathbf{0}, so \hat{\mathbf{y}}_t = \text{softmax}(2h_t, -2h_t).

Same weights at every step

Unrolling the loop draws one copy of the cell per step.

Every copy uses the same \mathbf{W}_{xh}, \mathbf{W}_{hh} and \mathbf{W}_{hy}. This is parameter sharing: a pattern learned at one position works at any position.

Example

3 state numbers, inputs of 5 numbers: 15 + 9 + 3 = 27 parameters in the state update, for any length T.

Figure 6:Folded cell (left) and the same cell unrolled over four steps.

Loss over a sequence

At each step the output is a probability for each class. The loss at step t is the cross-entropy: minus the log of the probability given to the correct class k_t.

L_t = -\log \hat{y}_{t,k_t}
(4)

The cost of the whole sequence is the average over its T steps:

J = \frac{1}{T} \sum_{t=1}^{T} L_t
(5)

Training lowers J with gradient descent, step size \alpha, as in Topic 23.

Example

Read “hell”, predict the next letter: e, l, l, o. Probabilities given to the correct letters: 0.5, 0.25, 0.8, 0.9.

Losses: 0.693, \ 1.386, \ 0.223, \ 0.105

J = 2.408 / 4 \approx 0.602

Backpropagation through time

The unrolled cell is an ordinary deep network. Run it forward and compute every L_t.

Backpropagation (Topic 23) sends gradients down from each loss and back along the states.

Shared weights add up the gradients of all steps.

Figure 8:A loss reaches an early state only through all the states after it.

Vanishing and exploding gradients

By the chain rule, the effect of an early state on a late one is a product with one factor per step:

\frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_1} = \frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_{T-1}} \cdots \frac{\partial \mathbf{h}_3}{\partial \mathbf{h}_2} \, \frac{\partial \mathbf{h}_2}{\partial \mathbf{h}_1}
(6)

With one state number, each factor is w_{hh}(1 - h_t^2), and 1 - h_t^2 \le 1:

\left| \frac{\partial h_T}{\partial h_1} \right| = \prod_{t=2}^{T} |w_{hh}| \, (1 - h_t^2) \ \le \ |w_{hh}|^{T-1}
(7)

Factors below 1 make the product vanish: early steps get almost no gradient. Factors above 1 can make it explode.

Example

T = 21: 20 factors, all equal:

0.5^{20} \approx 0.00000095

1.5^{20} \approx 3325

A small change per step becomes a huge change over 20 steps.

Shrink or blow up

Gradient reaching step 10

Clipping: a gradient longer than a threshold is scaled down to that length. It stops explosions. It does not cure vanishing.

Figure 9:Size of the gradient after going back k steps, |w_{hh}|^k, on a log scale. Clipping threshold 10.

Part 3

Remembering longer

Gates that decide what to keep, what to write and what to show.

The LSTM cell

The long short-term memory cell adds a second state, the cell state \mathbf{c}_t: a memory line that runs along the top.

Three gates control it. Each gate is a vector of numbers between 0 (closed) and 1 (open).

The cell state changes only by a product and a sum, so information can travel many steps with little loss.

Figure 10:One LSTM step. ⊙: elementwise product. ⊕: sum.

The three gates

Each gate is a small dense layer with a sigmoid. It reads the previous state and the new input, written side by side as [\mathbf{h}_{t-1}, \mathbf{x}_t].

Forget gate: how much of the old cell state to keep.

\mathbf{f}_t = \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f)
(8)

Input gate: how much of the new candidate to write.

\mathbf{i}_t = \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i)
(9)

Output gate: how much of the memory to show as \mathbf{h}_t.

\mathbf{o}_t = \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o)
(10)
Example

Suppose the three weighted sums are 2.2, −1.4 and 1.4:

f = \sigma(2.2) \approx 0.90: keep 90%

i = \sigma(-1.4) \approx 0.20: write 20%

o = \sigma(1.4) \approx 0.80: show 80%

Updating the cell

A candidate value is proposed with tanh, as in the plain cell:

\tilde{\mathbf{c}}_t = \tanh(\mathbf{W}_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c)
(11)

The new memory keeps part of the old one and writes part of the candidate:

\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t
(12)

The hidden state is the memory, squashed and filtered by the output gate:

\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t)
(13)
Example

Gates of the last slide, c_{t-1} = 2, \tilde{c}_t = 0.5:

c_t = 0.9 \cdot 2 + 0.2 \cdot 0.5 = 1.9

h_t = 0.8 \cdot \tanh(1.9)

= 0.8 \cdot 0.956 \approx 0.765

Why it helps

Along the memory line, the factor per step is \mathbf{f}_t. With \mathbf{f}_t near 1, the gradient does not vanish.

At step 1 the cell stores the value 1. After that, a new candidate arrives at every step.

The GRU

The gated recurrent unit is a lighter gated cell: no separate cell state and two gates instead of three.

Update gate \mathbf{z}_t: how much of the state to replace with the new candidate.

Reset gate \mathbf{r}_t: how much of the old state to use when the candidate \tilde{\mathbf{h}}_t is computed.

Both are sigmoid layers on [\mathbf{h}_{t-1}, \mathbf{x}_t]. The new state mixes old and new:

\mathbf{h}_t = (1 - \mathbf{z}_t) \odot \mathbf{h}_{t-1} + \mathbf{z}_t \odot \tilde{\mathbf{h}}_t
(14)

With fewer parameters it trains faster than an LSTM and often works as well.

Example

h_{t-1} = 0.8, \tilde{h}_t = -0.4, z_t = 0.25:

h_t = 0.75 \cdot 0.8 + 0.25 \cdot (-0.4)

= 0.6 - 0.1 = 0.5

Two extremes

z_t = 0: copy the old state. z_t = 1: take the candidate.

Applications

Next character: trained to predict the next letter, the network writes new text by feeding each output back as the next input.

Sentiment: read a review, classify the final state (Figure 4b).

Translation: an encoder reads the sentence into its final state; a decoder writes the translation from it.

Figure 12:(a) Text generation. (b) Encoder-decoder translation.

Limits and the next step

Slow to train: step t needs \mathbf{h}_{t-1}, so the steps of a sequence cannot run in parallel.

Long memory is still hard: the first word reaches the last only through every state in between, even with gates.

Attention links every position to every other directly. It is the basis of Transformers (Topic 31).

Figure 13:(a) A recurrent chain. (b) Attention from the last position.

Strengths and weaknesses

Table 2:Recurrent networks at a glance.

StrengthsWeaknesses
Handle sequences of any lengthSteps run one after another, so training is slow
Same weights at every step: few parametersPlain cells suffer vanishing and exploding gradients
The hidden state summarizes the pastVery long dependencies stay hard, even with gates
One cell covers many task shapesThe state is a fixed-size bottleneck
LSTM and GRU keep information over many stepsThe numbers in the state are hard to interpret
When to use it

Short and medium sequences, streams that arrive one item at a time, and tasks with little data or compute. For long texts, attention models usually do better.

Key ideas

Remember
  • A recurrent network reads a sequence step by step and keeps a hidden state as its memory.
  • Each step combines the old state and the new input with the same shared weights.
  • Training unrolls the network and applies backpropagation through time.
  • Long products of factors make gradients vanish or explode; clipping stops explosions.
  • LSTM and GRU gates decide what to keep and what to write, so memory lasts longer.
