Reading the symbols

Bold lowercase letters are vectors; bold capitals are matrices.

The superscript (l) names a layer. It is not a power.

The learning rate \alpha plays the same role as in linear and logistic regression: the size of each step.

A chain of simple functions

A network applies one simple function per layer, each to the output of the one before:

\hat{y} = f^{(L)}\Big(\dots f^{(2)}\big(f^{(1)}(\mathbf{x})\big)\Big)
(1)

Figure 3:Three steps: a line, a cut at zero, another line. Together they draw a bent line, which none of them draws alone.

Example

f^{(1)}(x) = 2x - 1

f^{(2)}(u) = \max(0, u)

f^{(3)}(v) = 3v + 0.5

At x = 2: 3 \to 3 \to \hat{y} = 9.5

At x = 0: -1 \to 0 \to \hat{y} = 0.5

Output \hat{y}9.50

One layer of units

Each unit takes a weighted sum of its inputs, adds a bias and applies the activation g:

\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}, \qquad \mathbf{a}^{(l)} = g\big(\mathbf{z}^{(l)}\big)
(2)

Figure 4:A layer with two inputs and two units. Weights sit on the arrows, biases next to the units. ReLU keeps positive sums and turns negative ones into 0.

Example

\mathbf{W} = \begin{bmatrix} 1 & -2 \\ 0.5 & 1 \end{bmatrix}

\mathbf{x} = (1, \ 2), \quad \mathbf{b} = (1, \ -1)

z_1 = 1 \cdot 1 - 2 \cdot 2 + 1 = -2

z_2 = 0.5 \cdot 1 + 1 \cdot 2 - 1 = 1.5

With ReLU: \mathbf{a} = (0, \ 1.5).

Why g?

Without it, a stack of layers collapses into one linear function.

Why depth helps

Each layer has two ReLU units that compute the same tent shape:

t(x) = 2\,\mathrm{ReLU}(x) - 4\,\mathrm{ReLU}(x - 0.5)

Part 2

Why now and how it learns

Large data sets, fast hardware and better methods made deep networks practical.

Why now?

(a) Data
labeled sets grew from thousands to millions of examples
(b) Compute
graphics cards do thousands of multiplications at once
(c) Methods
ReLU, dropout, better starting weights
(d) Scale
error keeps falling as data and models grow (sketch)

Figure 7:All three came together around 2010. AlexNet (2012) learned from 1.2 million images on two graphics cards in about six days. Older methods level off; bigger networks with more data keep improving.

Cost as average loss

The loss L scores one prediction. The cost averages it over the n training examples:

J(\boldsymbol{\theta}) = \frac{1}{n} \sum_{i=1}^{n} L\big(y_i, \hat{y}_i\big)
(3)

Figure 8:Squared loss (y - \hat{y})^2 on three examples. The cost is the height of the dashed line.

Training looks for the \boldsymbol{\theta}, every weight and bias, that makes J(\boldsymbol{\theta}) small.

Example

Targets 1, 0, 2; outputs 0.8, 0.4, 1.5.

Losses: 0.04, \ 0.16, \ 0.25.

J = \tfrac{0.04 + 0.16 + 0.25}{3} = 0.15.

Batches and epochs

In practice each step uses a batch of B examples. With n = 1000 and B = 50, one epoch takes 1000 / 50 = 20 steps.

One step downhill

The gradient points uphill. Gradient descent moves every parameter a small step the other way:

\boldsymbol{\theta} \ \leftarrow \ \boldsymbol{\theta} - \alpha \, \nabla_{\boldsymbol{\theta}} J(\boldsymbol{\theta})
(4)

Figure 9:Two steps on J(\theta) = (\theta - 3)^2 with \alpha = 0.1. The slope gets flatter near the bottom, so the steps get shorter.

Example

J(\theta) = (\theta - 3)^2, so J'(\theta) = 2(\theta - 3).

At \theta = 1: slope -4, J = 4.

\theta \leftarrow 1 - 0.1 \cdot (-4) = 1.4, J = 2.56.

Next: \theta = 1.72, J \approx 1.64.

In a network

The same rule updates millions of weights at once. Topic 23 shows how backpropagation finds every slope.

Many weights

AlexNet had about 60 million weights and 1.2 million training images. With so much freedom, a network can memorize noise.

Regularization

More data, or flipped and cropped copies of it.

A penalty on large weights.

Dropout: switch off random units while training.

Early stopping at the lowest validation cost.

When to use it

When there is a lot of data with structure, such as images, sound or text. For a small table of features, try the methods of chapter 3 first.

Key ideas

Remember
  • Deep learning learns the features itself, layer by layer, from raw data.
  • A network chains simple layers: weighted sum, bias, activation g.
  • Depth builds complex shapes from few units.
  • Training lowers the cost J(\boldsymbol{\theta}) by gradient descent; \alpha sets the step.
  • The kind of data picks the architecture: CNNs for images, RNNs and Transformers for sequences.
