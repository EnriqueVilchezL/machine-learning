Part 1

Images as numbers

A computer sees a picture as a table of brightness values.

An image is a grid

A grayscale image is a table with one number per pixel: 0 is black, 255 is white.

A color image has three tables of the same size, one per channel: red, green and blue. Its shape is H \times W \times 3.

Figure 1:(a) A handwritten 7 as 8 × 8 pixels. (b) A color image: three stacked channels.

Dense layers on images

Recap of Topic 23: a dense layer has one weight per input and neuron.

\mathbf{a} = g(\mathbf{W}\mathbf{x} + \mathbf{b})

Too many weights: a 200 × 200 color image has 120 000 inputs; 1 000 neurons need 120 million weights.

No sense of place: flattening loses the neighbours, and a shifted object lights up other inputs.

Figure 2:(a) Dense layer, 4 × 4 image. (b) A shifted stroke.

Two ideas

Local connections: each output looks only at a small patch of neighbouring inputs.

Shared weights: every patch uses the same few weights, so a pattern is detected wherever it appears.

Together, the two ideas give the convolution.

Figure 3:Seven inputs, five outputs, drawn in one dimension. In (c) each color is one weight, reused at every position.

Part 2

Convolution and pooling

Slide a small filter over the image, then shrink the result.

The convolution

Place the k \times k kernel on the image with its corner at row i, column j. Multiply the overlapping numbers, add them up, and add the bias:

Z_{ij} = \sum_{m=0}^{k-1} \sum_{n=0}^{k-1} X_{i+m,\,j+n} \, K_{mn} + b
(1)

Moving the kernel to every position fills the feature map \mathbf{Z}. A large Z_{ij} means the patch looks like the kernel.

The weights K_{mn} and the bias b are learned, like any other weights. Strictly this is a cross-correlation; deep learning calls it convolution.

Example

Patch and kernel, with b = 1:

\begin{bmatrix} 3 & 1 \\ 4 & 2 \end{bmatrix}, \ \begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix}

3 \cdot 1 + 1 \cdot 0 + 4 \cdot 0

+ \, 2 \cdot (-1) + 1 = 2

Size

A 4 × 4 image and a 3 × 3 kernel give 2 × 2 positions, so \mathbf{Z} is 2 × 2.

A worked example

This kernel adds the left column of the patch and subtracts the right column. The bias is 0.

Press → to move the kernel one position at a time.

The largest value, 11, is where the image is bright on the left and dark on the right: a vertical edge.

Output size

Two settings change how many positions the kernel visits:

Padding p adds a border of zeros around the image. Stride s is how many pixels the kernel jumps each move.

For an n \times n input and a k \times k kernel, the output is n_{\text{out}} \times n_{\text{out}} with

n_{\text{out}} = \left\lfloor \frac{n + 2p - k}{s} \right\rfloor + 1
(2)

\lfloor \cdot \rfloor rounds down: a last step that would leave the image is skipped. With s = 1 and p = (k-1)/2 the size does not change.

Example

n = 32, \ k = 5, \ p = 0, \ s = 1:

\tfrac{32 - 5}{1} + 1 = 28

n = 7, \ k = 3, \ p = 0, \ s = 2:

\lfloor \tfrac{7 - 3}{2} \rfloor + 1 = 3

Same size

n = 32, \ k = 3, \ p = 1, \ s = 1:

\tfrac{32 + 2 - 3}{1} + 1 = 32

Channels and filters

With C input channels, each kernel is k \times k \times C. Filter f sums over all channels and gives one map:

Z^{(f)}_{ij} = \sum_{c=1}^{C} \sum_{m=0}^{k-1} \sum_{n=0}^{k-1} X_{i+m,\,j+n,\,c} \, K^{(f)}_{mnc} + b^{(f)}
(3)
In words

Each filter looks for one pattern. F filters give F maps, stacked as the channels of the next layer.

Example

Input 32 \times 32 \times 3, F = 16 filters of size 5 \times 5 \times 3.

Each filter: 5 \cdot 5 \cdot 3 = 75 weights and 1 bias.

Output: 28 \times 28 \times 16.

Figure 7:Four filters on a color image give four feature maps.

ReLU after convolution

As in Topic 23, a nonlinearity follows each layer. ReLU acts on every entry of the feature map:

A_{ij} = \max(0, \, Z_{ij})

Without it, a stack of convolutions would equal one single convolution.

Example

\max(0, -6) = 0, \ \max(0, 4) = 4

Figure 8:Negative entries (blue) become 0; positive entries (orange) pass unchanged.

Pooling

Pooling keeps one number per 2 × 2 window (stride 2), so each map shrinks by half.

Max pooling keeps the largest value; average pooling keeps the mean.

No weights to learn, and small shifts rarely change the result.

Example

Top-left window \{1, 3, 5, 2\}: max 5, average \tfrac{11}{4} = 2.75.

Figure 9:Circles: the values max pooling keeps.

Counting parameters

A convolutional layer has F filters, each with k \cdot k \cdot C weights and one bias:

\text{params}_{\text{conv}} = F \, (k \cdot k \cdot C + 1)
(4)

A dense layer with n_{\text{in}} inputs and n_{\text{out}} neurons needs one weight per pair, plus one bias per neuron:

\text{params}_{\text{dense}} = (n_{\text{in}} + 1) \, n_{\text{out}}
(5)

Equation (4) does not contain the image size: the same weights work on a small or a large image.

Example: conv

Color input (C = 3), F = 64 filters of 3 \times 3:

64 \cdot (3 \cdot 3 \cdot 3 + 1)

= 64 \cdot 28 = 1\,792

Example: dense

200 \times 200 \times 3 = 120\,000 inputs, 1 000 neurons:

120\,001 \cdot 1\,000 = 120\,001\,000

Part 3

Building a CNN

Stack the blocks, train them with backpropagation, and use them.

A typical CNN

Repeat convolution, ReLU and pooling. Then flatten, and finish with a dense layer and softmax (Topic 23).

Figure 10:A small network for 28 × 28 digit images, in the style of LeNet-5. Maps get smaller and more numerous; orange numbers count the parameters of each layer.

What the layers learn

Nobody designs the kernels: training finds them. Early layers find simple patterns; later layers combine them.

Figure 11:Schematic view of the patterns that make neurons fire, from the first layer to the last.

Receptive field

The receptive field: input pixels one neuron sees. Stride 1:

r = 1 + L\,(k - 1)
Example: L = k = 3

r = 1 + 3 \cdot 2 = 7

Figure 12:Orange: what the top neuron sees.

Training a CNN

Softmax gives a probability per class. For one image with true class t, the cross-entropy loss is

L = -\log \hat{y}_{t}
(6)

Backpropagation gives the gradient for every kernel, bias and dense weight in \boldsymbol{\theta}. Gradient descent then updates them:

\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \alpha \, \frac{\partial J}{\partial \boldsymbol{\theta}}
(7)

A shared weight is used at every position, so its gradient adds up the contributions of all positions:

\frac{\partial L}{\partial K_{mn}} = \sum_{i} \sum_{j} \frac{\partial L}{\partial Z_{ij}} \, X_{i+m,\,j+n}
(8)
Example: loss

Softmax gives the true class \hat{y}_t = 0.7:

L = -\log 0.7 \approx 0.36

Example: shared weight

Two positions with \partial L / \partial Z = 0.5 and -0.2, and inputs 2 and 1 under K_{mn}:

0.5 \cdot 2 + (-0.2) \cdot 1 = 0.8

Data augmentation

CNNs need many labeled images. Small changes that keep the label create new training examples for free.

Figure 13:One training image and four new versions. The network learns that the label does not depend on these changes.

Famous architectures

Networks grew deeper. ResNet made very deep ones trainable with a skip connection: a block's input is added to its output.

\mathbf{a}^{(l+2)} = g\big(\mathbf{z}^{(l+2)} + \mathbf{a}^{(l)}\big)
Example

(-0.3, \, 0.5) + (0.8, \, 0.2) = (0.5, \, 0.7); ReLU keeps (0.5, \, 0.7).

If \mathbf{z}^{(l+2)} = \mathbf{0}, the block passes \mathbf{a}^{(l)} through unchanged.

Figure 14:Bar height: number of layers (log scale).

Beyond classification

The same convolutional layers can feed other outputs.

Detection: a box and a label for each object. Segmentation: a class for every pixel.

Medical images: find tumours in scans or count cells. A network trained on one task can be reused for another (Topic 29).

Figure 15:Four tasks on images, drawn schematically.

Strengths and weaknesses

Table 2:Convolutional networks at a glance.

StrengthsWeaknesses
Few weights, thanks to local connections and sharingNeed many labeled images to train from scratch
Find a pattern anywhere in the imageTraining takes a lot of computing time
Learn their own features, from edges to objectsHard to explain why a decision was made

When to use it

The standard choice for images and other grid data, especially when a pretrained network for a similar task exists.

Key ideas

Remember
  • An image is a grid of numbers with height, width and channels.
  • A convolution slides a small learned kernel over the image; local connections and shared weights keep the weight count small.
  • Padding and stride set the output size; pooling shrinks the maps.
  • A CNN stacks conv, ReLU and pooling, then dense layers and softmax; deeper layers see larger patches and more complex patterns.
  • It is trained with cross-entropy and backpropagation, helped by data augmentation and skip connections.
