Part 1

From neuron to network

A weighted sum and a bend, repeated in layers.

The artificial neuron

A neuron multiplies each input by a weight, adds them up with a bias b, and passes the sum through an activation function g:

z = \sum_{k=1}^{d} w_k x_k + b = \mathbf{w}^\top \mathbf{x} + b
(1)
a = g(z)
(2)
Example

\mathbf{x} = (1, 2, -1)

\mathbf{w} = (0.8, 0.2, -0.5), b = -0.3

z = 0.8 + 0.4 + 0.5 - 0.3

\phantom{z} = 1.4

Sigmoid: \sigma(1.4) \approx 0.80

Old friend

One neuron with g = \sigma is logistic regression (Topic 11).

Figure 1:The neuron of the example. Weights sit on the arrows.

The perceptron

Rosenblatt’s perceptron (1958): \hat{y} = 1 when \mathbf{w}^\top\mathbf{x} + b \ge 0, else 0. Its boundary is a line.

Points correct4 / 4

Figure 2:The inputs of a logic gate. No line gets XOR right.

Two layers solve XOR

Hidden unit h_1 computes OR, h_2 computes AND. The output says 1 when h_1 is on and h_2 is off.

h_1 = \text{step}(x_1 + x_2 - 0.5)

h_2 = \text{step}(x_1 + x_2 - 1.5)

\hat{y} = \text{step}(h_1 - h_2 - 0.5)

Example

Input (1, 1): h_1 = 1, h_2 = 1, so \hat{y} = \text{step}(-0.5) = 0.

Figure 3:(a) Weights on the arrows. (b) After the hidden layer, one line separates the classes.

Activation functions

Without a bend, stacked layers stay one weighted sum.

\sigma(z) = \dfrac{1}{1 + e^{-z}}
\sigma' = \sigma(1 - \sigma)
\tanh z = \dfrac{e^{z} - e^{-z}}{e^{z} + e^{-z}}
\tanh' = 1 - \tanh^2
\text{ReLU}(z) = \max(0, z)

Layers and the forward pass

A layer is a row of neurons that read the same input. Each unit’s weights form one row of \mathbf{W}^{(l)}, so the layer works in one step:

\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}
(3)
\mathbf{a}^{(l)} = g(\mathbf{z}^{(l)}), \qquad \mathbf{a}^{(0)} = \mathbf{x}, \quad \hat{\mathbf{y}} = \mathbf{a}^{(L)}
(4)

The forward pass applies (3) and (4) for l = 1, \dots, L. Each layer’s output is the next layer’s input.

Example: sizes

784 pixels in, 10 hidden units, 4 outputs.

\mathbf{W}^{(1)} is 10 \times 784: 7 840 weights.

\mathbf{W}^{(2)} is 4 \times 10: 40 weights.

With the biases: 7840 + 10 + 40 + 4 = 7894 parameters.

Figure 5:The forward pass as a chain of layers.

A forward pass by hand

ReLU hidden layer, sigmoid output. Input \mathbf{x} = (1, 2), target y = 1.

z_1 = 0.5 - 0.5 + 0.5 = 0.5

z_2 = 0.25 + 1 + 0 = 1.25

\mathbf{a}^{(1)} = \text{ReLU}(\mathbf{z}^{(1)}) = (0.5, 1.25)

z^{(2)} = 0.5 - 1.25 + 0 = -0.75

\hat{y} = \sigma(-0.75) \approx 0.32

L = -\log 0.32 \approx 1.14

Figure 6:A 2-2-1 network. Weights on the arrows, biases next to the units.

Output layers

The task decides the last layer. For K classes, softmax turns K scores into probabilities that add up to 1:

\hat{y}_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}
(5)
Example

\mathbf{z} = (2, 1, 0): e^{z} \approx (7.39, 2.72, 1), sum 11.11

\hat{\mathbf{y}} \approx (0.67, 0.24, 0.09)

Figure 7:Three output layers. Hidden layers stay the same; only the last layer changes.

Part 2

Learning the weights

Measure the error, then send it back through the network to fix every weight.

Loss and cost

A loss L(y, \hat{y}) measures how wrong one prediction is. For a number, the squared error:

L(y, \hat{y}) = (y - \hat{y})^2
(6)

For classes, the cross-entropy, with y_k = 1 for the true class and 0 for the rest:

L(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{k=1}^{K} y_k \log \hat{y}_k
(7)

The cost averages the loss over the n training examples. Training looks for the \boldsymbol{\theta} that makes it small:

J(\boldsymbol{\theta}) = \frac{1}{n} \sum_{i=1}^{n} L(\mathbf{y}_i, \hat{\mathbf{y}}_i)
(8)
Example

True answer y = 1, natural log.

\hat{y} = 0.8: squared 0.04, cross-entropy 0.22

\hat{y} = 0.1: squared 0.81, cross-entropy 2.30

In words

Only the true class counts in (7): the loss is -\log of its probability. With two classes it is the log-loss of Topic 11.

Gradient descent

The gradient \nabla_{\boldsymbol{\theta}} J holds the slope of J along every parameter and points uphill. Gradient descent steps the other way:

\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \alpha \, \nabla_{\boldsymbol{\theta}} J(\boldsymbol{\theta})
(9)

The learning rate \alpha sets the step size. Too small and training is slow; too large and the steps overshoot.

Example

J(\theta) = \theta^2, slope 2\theta, start \theta = 3.

\alpha = 0.1: 3 - 0.1 \cdot 6 = 2.4, then 1.92, then 1.54

\alpha = 0.9: 3 - 5.4 = -2.4, then 1.92. It jumps across the bottom.

Figure 8:Five steps on the curve of the example.

Batches and epochs

Each step of (9) averages the gradient over:

Batch: all n examples. Smooth, slow.
Mini-batch: B examples. Usual.
Stochastic: one. Cheap, noisy.

Example

An epoch is one pass over the data. n = 1000, B = 50: 20 steps per epoch.

Figure 9:Paths to the lowest cost. Rings: equal J.

The chain rule

Take one neuron: z = w \, a^{(l-1)} + b, a = \sigma(z), L = (a - y)^2. To see how L reacts to w, multiply the local slopes along the path:

\frac{\partial L}{\partial w} = \frac{\partial z}{\partial w} \, \frac{\partial a}{\partial z} \, \frac{\partial L}{\partial a} = a^{(l-1)} \cdot \sigma(z)\big(1 - \sigma(z)\big) \cdot 2(a - y)
(10)
Example

a^{(l-1)} = 1, w = 0.5, b = 0, y = 1

z = 0.5, a = \sigma(0.5) \approx 0.622

\partial L / \partial a \approx -0.755

\partial a / \partial z \approx 0.622 \cdot 0.378 \approx 0.235

Product: 1 \cdot 0.235 \cdot (-0.755)

\partial L / \partial w \approx -0.177

Figure 10:Values flow forward in gray, slopes flow back in orange.

Backpropagation

Backpropagation applies the chain rule to all layers in one backward sweep. It starts with the error at the output:

\boldsymbol{\delta}^{(L)} = \hat{\mathbf{y}} - \mathbf{y}
(11)

Each earlier layer receives the error back through the same weights, scaled by the slope of its activation:

\boldsymbol{\delta}^{(l)} = \big(\mathbf{W}^{(l+1)}\big)^{\top} \boldsymbol{\delta}^{(l+1)} \odot g'(\mathbf{z}^{(l)})
(12)

Each gradient is an error term times the input of its layer:

\frac{\partial J}{\partial \mathbf{W}^{(l)}} = \boldsymbol{\delta}^{(l)} \big(\mathbf{a}^{(l-1)}\big)^{\top}, \qquad \frac{\partial J}{\partial \mathbf{b}^{(l)}} = \boldsymbol{\delta}^{(l)}
(13)
Example

Figure 6: \hat{y} = 0.32, y = 1.

\delta^{(2)} = 0.32 - 1 = -0.68

Negative: the output is too low, so the step in (9) raises it.

When (11) holds

For a sigmoid or softmax output with cross-entropy loss, one example at a time.

Symbol

\odot multiplies two vectors entry by entry.

A backward pass by hand

Network and input of Figure 6.

\partial J / \partial \mathbf{W}^{(2)} = -0.68 \cdot (0.5, 1.25)
= (-0.34, -0.85)

\boldsymbol{\delta}^{(1)} = (1, -1) \cdot (-0.68) \odot (1, 1)
= (-0.68, 0.68)

\partial J / \partial w^{(1)}_{jk} = \delta^{(1)}_j \, x_k

Step (9) with \alpha = 0.1, then forward again: \hat{y} \approx 0.56, L \approx 0.58.

Starting weights and depth

Not all zeros

Equal weights keep all units identical. Start small and random, about 1/\sqrt{n_{\text{in}}} (Glorot and Bengio, 2010).

Vanishing gradients

By (12), each layer multiplies the error by g' \le 0.25 for the sigmoid. After 10 layers: 0.25^{10} \approx 10^{-6}.

ReLU helps

Its slope is 1 on active units, so the error reaches the first layers.

Figure 14:(a) Zero start. (b) Error per layer.

Overfitting and regularization

Weight decay penalizes large weights:

J(\boldsymbol{\theta}) + \lambda \lVert \mathbf{W} \rVert^2
(14)

Dropout switches off random units at each step.

Early stopping keeps the weights with the lowest validation cost.

Example

Weights (3, -4), \lambda = 0.01: penalty 0.01 \cdot 25 = 0.25.

Figure 15:(a) Illustrative costs. (b) Dropout.

Universal approximation

With enough units, one hidden layer follows any smooth curve:

\hat{y} = c + \textstyle\sum_{j} v_j \, g(w_j x + b_j)

Strengths and weaknesses

Table 2:Neural networks at a glance.

StrengthsWeaknesses
Learn curved boundaries and features from raw inputsNeed many examples to fit many weights
One recipe for regression and any number of classesMany choices: layers, units, activation, \alpha
Backpropagation gives all gradients in one sweepThe cost has many local minima; results depend on the start
Layers stack into the deep models of the next topicsWeights are hard to read and explain
Prediction is fast once trainedTraining can be slow and overfits without regularization
When to use it

When the data set is large and the pattern is too curved for linear models or simple features.

Key ideas

Remember
  • A neuron is a weighted sum plus a bias, bent by an activation function.
  • One neuron draws a line; hidden layers bend the space, so XOR and curved boundaries become possible.
  • The forward pass repeats \mathbf{a}^{(l)} = g(\mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}) up to the output.
  • Backpropagation sends the error back with the chain rule; gradient descent then updates every weight.
  • Random starts, ReLU and regularization keep training stable and the model general.
