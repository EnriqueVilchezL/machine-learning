Models as functions

A model takes the d features of an example and returns a label:

f : \mathbb{R}^d \to \mathcal{Y}, \qquad \hat{y} = \hat{f}(\mathbf{x})
(1)

The set of possible labels \mathcal{Y} decides the task. Classification has C classes; regression has any real number:

\text{classification: } \mathcal{Y} = \{c_1, \dots, c_C\}, \qquad \text{regression: } \mathcal{Y} = \mathbb{R}
(2)

Training uses \mathcal{D} to choose one function \hat{f}. Predicting means evaluating it at a new \mathbf{x}.

Example

Diagnosis (Table 2), with d = 2:

\mathbf{x} = (\text{glucose}, \text{pressure})

\mathcal{Y} = \{\text{diabetes}, \text{no diabetes}\}, C = 2.

House prices: \mathcal{Y} = \mathbb{R}, and \hat{y} is a price.

Measuring performance

Counting the right and wrong answers on data the model has not seen.

The confusion matrix

Accuracy0%
Precision0%

Precision: of the flagged emails, the share that is spam. Recall: of the spam emails, the share we flagged.

Figure 4:50 test emails, 20 of them spam. Emails with a score above the threshold are flagged.

Counting right and wrong

Call the four cells TP, FP, FN and TN: true positives, false positives, false negatives and true negatives.

\text{accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}}
(3)
\text{precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \qquad \text{recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}
(4)

Precision divides by the emails we flagged. Recall divides by the emails that really are spam.

Example

50 emails, 20 of them spam.

TP = 15, FN = 5
FP = 3, TN = 27

\text{accuracy} = \tfrac{42}{50} = 84\%

\text{precision} = \tfrac{15}{18} \approx 83\%

\text{recall} = \tfrac{15}{20} = 75\%

Losses and average error

A loss L(y, \hat{y}) scores one prediction. Three common ones:

L_{0\text{-}1} = \mathbb{I}(y \neq \hat{y}), \qquad L_{\text{abs}} = |y - \hat{y}|, \qquad L_{\text{sq}} = (y - \hat{y})^2
(5)

Averaging a loss over n examples gives one number for the whole set:

\frac{1}{n} \sum_{i=1}^{n} L\big(y_i, \hat{f}(\mathbf{x}_i)\big)
(6)

With the 0-1 loss this is the error rate, 1 - \text{accuracy}. With the absolute loss it is the average error of Figure 5b; with the squared loss, the mean squared error.

Example

Labels 3, 5, 10; predictions 4, 3, 7. Gaps: 1, 2, 3.

\text{abs:}\ \tfrac{1 + 2 + 3}{3} = 2

\text{sq:}\ \tfrac{1 + 4 + 9}{3} \approx 4.67

Fraud model of Figure 5a: 2 mistakes in 100, error rate 0.02.

Models and their assumptions

Every method draws boundaries in its own way.

Simple and wiggly boundaries

(a) A straight line
(b) A boundary that bends
Model family

The set of shapes a method can draw: all straight lines, or all boundaries made of small pieces.

Parameters

The numbers training picks inside that family, such as the slope and position of the line.

Figure 6:The same 60 examples. (a) misses a few points; (b) puts every training point on its side.

Learning as minimizing loss

The average training loss of a model f is its empirical risk:

\hat{R}(f) = \frac{1}{n} \sum_{i=1}^{n} L\big(y_i, f(\mathbf{x}_i)\big)
(7)

Training searches the model family \mathcal{F} for the member with the smallest empirical risk:

\hat{f} = \underset{f \in \mathcal{F}}{\arg\min} \ \hat{R}(f)
(8)

For lines, searching \mathcal{F} means searching the slope and position: the parameters.

Example

10 training points, 0-1 loss.

Line A misses 3: \hat{R} = 0.3.

Line B misses 1: \hat{R} = 0.1.

Training keeps line B.

The generalization gap

The training error \text{Err}_{\text{train}} = \hat{R}(\hat{f}) is measured on the examples used to fit. The test error is the same average on new examples.

\text{gap} = \text{Err}_{\text{test}} - \text{Err}_{\text{train}}
(9)

Underfitting: both errors are high and the gap is small.

Overfitting: the training error is near 0 and the gap is large. A low \hat{R} alone does not prove a good model.

Too simple: 0.25 and 0.27, so the gap is 0.02.

Key ideas

Remember
  • Supervised learning fits a function from inputs to labels, using examples that come with the answer.
  • Classification predicts a category; regression predicts a number.
  • A classifier splits the feature space with a decision boundary.
  • With rare classes, look at the confusion matrix, precision and recall, not only accuracy.
  • Each method assumes something about the data; no method wins on every problem.
