Part 1

The widest street

Many lines separate the classes. A support vector machine picks the one with the most room on both sides.

Many possible lines

Each email is a point. A straight line, the decision boundary, puts spam on one side.

The line holds the points where a weighted sum of the features minus a threshold is zero. In more dimensions: a hyperplane.

A, B and C make no mistakes. Which would you trust with new mail?

Figure 1:22 emails, normal (blue) and spam (orange), and three lines that separate them.

The line as a formula

Give each feature a weight w_j. The boundary holds the points where the weighted sum plus an offset b is zero:

\mathbf{w}^\top \mathbf{x} + b = w_1 x_1 + w_2 x_2 + \cdots + w_d x_d + b = 0
(1)

Points on one side give a positive value, points on the other side a negative one. The sign is the prediction:

\hat{y} = \operatorname{sign}(\mathbf{w}^\top \mathbf{x} + b)
(2)

\mathbf{w} sets the tilt of the line and b slides it. Training means choosing both.

Example

Take \mathbf{w} = (2, 1), b = -4 and an email with \mathbf{x} = (3, 1).

2 \cdot 3 + 1 \cdot 1 - 4 = 3 > 0

\Rightarrow \ \hat{y} = +1: spam.

The street in formulas

Distance from a point to the line: the value of the formula divided by the length of \mathbf{w}.

\text{dist}(\mathbf{x}) = \frac{|\mathbf{w}^\top \mathbf{x} + b|}{\lVert \mathbf{w} \rVert}, \qquad \lVert \mathbf{w} \rVert = \sqrt{w_1^2 + \cdots + w_d^2}
(3)

Scale \mathbf{w} and b so the edges of the street are \mathbf{w}^\top \mathbf{x} + b = \pm 1. The width is then

\text{margin} = \frac{2}{\lVert \mathbf{w} \rVert}
(4)

A small \lVert \mathbf{w} \rVert means a wide street. Keep every point on its side and outside the street:

\min_{\mathbf{w}, b} \ \tfrac{1}{2} \lVert \mathbf{w} \rVert^2 \quad \text{subject to} \quad y_i (\mathbf{w}^\top \mathbf{x}_i + b) \ge 1 \ \text{ for all } i
(5)
Example

Take \mathbf{w} = (3, 4) and b = -5.

\lVert \mathbf{w} \rVert = \sqrt{9 + 16} = 5

Margin: 2/5 = 0.4

Point (2, 1): 6 + 4 - 5 = 5

Distance: 5/5 = 1

With y = +1: 5 \ge 1, so the point is outside the street.

Why the widest street

Drive in the middle of the road

A driver who hugs one curb hits it at the first small swerve. In the middle there is room for error on both sides.

New points are never exactly like the training points. The widest street, the maximum margin, leaves the most room for that variation, so it tends to generalize better.

Figure 3:Three new normal emails (diamonds) arrive. The narrow street misclassifies two of them, the widest street none.

Part 2

Support vectors and soft margins

Only a few points decide the street. Real data overlaps, so the street must allow some mistakes.

Only the closest points matter

The points on the edges of the street are the support vectors. They hold the street in place.

Drag a far point: nothing changes. Drag a ringed point: the line moves.

Soft margin

When classes overlap, no street is empty. The soft margin lets points enter the street or cross it, at a price set by C.

Figure 5:Small C: wide street, many violations (ringed). Large C: narrow street, few violations.

Paying for violations

Give each point a slack \xi_i \ge 0: how far it may enter the street. Each unit of slack costs C.

\min_{\mathbf{w}, b, \xi} \ \tfrac{1}{2} \lVert \mathbf{w} \rVert^2 + C \sum_{i=1}^{n} \xi_i \quad \text{subject to} \quad y_i (\mathbf{w}^\top \mathbf{x}_i + b) \ge 1 - \xi_i
(6)

Write f(\mathbf{x}) = \mathbf{w}^\top \mathbf{x} + b. The smallest slack that works is the hinge loss:

\xi_i = \max\big(0, \ 1 - y_i f(\mathbf{x}_i)\big)
(7)

Large C: slack is expensive, so the street narrows. Small C: slack is cheap, so the street widens.

Example

Three spam emails, y = +1:

f = 2: outside the street, \xi = 0.

f = 0.4: inside the street, \xi = 0.6.

f = -0.5: wrong side, \xi = 1.5.

Kernels and settings

When no straight line works, add a feature so that one does.

Add a feature

Normal values sit in the middle, unusual ones at both ends. No single cut point separates them.

Add a second feature, the value squared. The points rise onto a parabola and a flat line now works.

No line separates them

Figure 6:14 points on one feature. Lifted, the blue points stay low and the orange ones rise.

From a ring to a bowl

A kernel computes how similar two points are as if the extra features were there, without building them. This shortcut is the kernel trick.

A flat cut in the bigger space becomes a curved boundary back in the original space: here, the dashed circle.

Figure 7:Left: a ring of orange points around a blue cluster. Right: the same points lifted by their squared distance to the center; a flat plane splits them.

Curved boundaries

The RBF kernel (radial basis function) measures similarity by closeness. Its width sets how far each point reaches.

Kernel formulas

Let \varphi(\mathbf{x}) add the extra features. A kernel gives their dot product directly, without building them:

K(\mathbf{x}, \mathbf{x}') = \varphi(\mathbf{x})^\top \varphi(\mathbf{x}')
(8)

The RBF kernel is 1 for identical points and drops toward 0 as they move apart. A large \gamma means a narrow kernel.

K(\mathbf{x}, \mathbf{x}') = \exp\big(-\gamma \lVert \mathbf{x} - \mathbf{x}' \rVert^2\big)
(9)

The prediction is a weighted sum of similarities to the support vectors (SV), with weights \alpha_i \ge 0 found in training:

\hat{y} = \operatorname{sign}\Big(\sum_{i \in \text{SV}} \alpha_i \, y_i \, K(\mathbf{x}_i, \mathbf{x}) + b\Big)
(10)
Example

RBF with \gamma = 0.5 for two points:

\mathbf{x} = (1, 2), \ \mathbf{x}' = (2, 3)

\lVert \mathbf{x} - \mathbf{x}' \rVert^2 = 1 + 1 = 2

K = e^{-0.5 \cdot 2} = e^{-1} \approx 0.37

For the same point twice, K = e^{0} = 1.

Settings and scaling

Table 2:The three main settings of an SVM and what happens at each extreme.

SettingSmall or simpleLarge or complex
CWide street, many violations allowed, risk of underfittingNarrow street, few violations, risk of overfitting
KernelLinear: a straight boundaryPolynomial or RBF: curved boundaries
Kernel widthWide: smooth boundary, close to a lineNarrow: wiggly boundary that follows single points

Choose C and the kernel width with cross-validation (Topic 6): try a grid of values and keep the pair with the best validation score.

Scale first

The street width is a distance. A feature measured in colones would swamp one measured in years, so scale the features first (Topic 4).

Start simple

Try a linear kernel first. Move to RBF only if the straight line underfits.

Strengths and weaknesses

Table 3:When an SVM is a good choice and when it is not.

StrengthsWeaknesses
The maximum margin tends to generalize wellSlow to train with hundreds of thousands of rows

Kernels give curved boundariesC and the kernel width must be tuned
The model depends only on the support vectorsNo direct probability for each prediction
One clear answer: the widest street is uniqueA kernel model is hard to explain
Good fit

Text classification, such as spam filtering, with many word features and a few thousand examples.

Compared with logistic regression

Both draw a line. Logistic regression listens to every point; the SVM only to the points near the boundary (Topic 11).

Key ideas

Remember
  • An SVM separates two classes with the line that leaves the widest street.
  • A wide margin leaves room for new points, so it tends to generalize better.
  • Only the support vectors, the points on the edges of the street, define the model.
  • The soft margin allows some violations; C trades street width against mistakes.
  • Kernels add features implicitly, so a flat cut becomes a curved boundary.
  • Scale the features and tune C and the kernel width with cross-validation.
